# Fitness Tracker App 💪

A simple and user-friendly Fitness Tracker built using HTML, CSS, and JavaScript.

## Features
- Track daily fitness activities
- Add walking, running and other activities
- Record steps, calories burned and duration
- View total steps, calories and minutes
- View activity history
- Delete activities
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start tracking your fitness activities!
